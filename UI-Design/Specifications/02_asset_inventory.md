# Zellige: Asset Inventory and Unity Import Guide

Every PNG in `UI-Design/Exported/` is generated by script, so nothing is hand-edited. Regenerate everything with:

```
python UI-Design/Generated/tools/build_all.py
```

Run it from the repository root (it also works from any directory). It needs Python 3 with Pillow and takes about 15 s.

## 1. Common import settings (all sprites unless noted)

| Setting | Value |
|---|---|
| Texture Type | Sprite (2D and UI) |
| Sprite Mode | Single |
| Mesh Type | **Full Rect** (required for sliced sprites; also recommended for all UI) |
| Pixels Per Unit | 100 (Canvas `Reference Pixels Per Unit` = 100) |
| Wrap Mode | Clamp |
| Filter Mode | Bilinear |
| Generate Mip Maps | Off (see the note on cards in §4) |
| sRGB | On |
| Alpha Is Transparency | On (for RGBA assets) |
| Compression | Standalone: **None** for cards, icons and small UI (crisp edges, small atlas). **Normal Quality** is acceptable for `bg_table_main`. |
| Max Size | 2048 for the background, 512 for cards and all other assets |

9-slice borders are entered in the Sprite Editor in Unity's order, **L / B / R / T**, in pixels of the source PNG. For sliced sprites, use `Image.type = Sliced`. If an element is shown much smaller than its source, set `Image.pixelsPerUnitMultiplier` (for example 1.5–2) so the corners shrink with it.

## 3. Card generator

Source: `UI-Design/Generated/tools/gen_cards.py` (shared helpers and palette in `zellige_common.py`).

```
python UI-Design/Generated/tools/gen_cards.py --all                 # 40 faces + back + suits + blank
python UI-Design/Generated/tools/gen_cards.py --sample              # the 6 review faces only
python UI-Design/Generated/tools/gen_cards.py --suit copas --rank 5 # one card
  --cards-out DIR   faces + back      (default UI-Design/Exported/cards)
  --out DIR         suits + blank     (default UI-Design/Exported)
  --width 360 --height 540            output size (layout scales from a 360x540 design grid)
  --ss 4                              supersampling factor (rendered 4x, LANCZOS downsample)
  --font PATH                         numeral font, rasterised only (default Cambria Bold)
  --no-base                           skip suits / blank / back
```

How a face is composed from `(suit, rank)`:

1. **Stock:** ivory gradient, edge line, inner frame. Court ranks add a gold inner frame.
2. **Body:** for ranks 1–7, a table `layouts[rank]` gives pip size and pip positions in the 360 × 540 design grid. Suit symbols are drawn as vectors from `_suit_layer(suit)`, outlined in the suit's dark colour, and cached per size. For ranks 10–12, a suit-tinted star medallion with the large symbol, an ornament keyed by rank (star / horseshoe / crown), and `rank − 9` gold diamonds.
3. **Indices:** rank numeral plus small pip top-left, the same rotated 180° bottom-right. Two-digit ranks are auto-fitted to width.
4. **Finish:** rounded-corner alpha mask, then downsample.

To change a colour or the layout for the whole deck, edit `SUITS`/`PAL` in `zellige_common.py` or `layouts` in `gen_cards.py` and rerun. Outputs are deterministic (the felt noise in the background is the only random element).

## 4. Notes and caveats for integration

* **Card minification:** cards are displayed at 0.39–0.49× their source size. With mipmaps off and bilinear filtering, edges stay acceptable, as the 140 px contact sheet shows. If shimmering appears during animated scaling, enable **Generate Mip Maps** on the cards atlas only, with Trilinear filtering. Alternatively, regenerate at `--width 240 --height 360` for a lower-resolution build.
* **Fonts:** see 01_visual_identity.md §3 on Cambria versus OFL fonts for card numerals.
* No exported asset contains words. Call-outs, names, scores and button labels are all TMP.
